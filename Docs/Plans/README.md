# Plans

Use this directory for cross-cutting production plans and decision records.

A plan should state:

- the outcome and user value;
- current-state constraints;
- proposed architecture or product behavior;
- alternatives and tradeoffs;
- dependencies and migration strategy;
- validation, rollout, and rollback criteria;
- unresolved decisions.

Plans should reference supporting research and decompose into tickets only after
the major decisions are explicit.
