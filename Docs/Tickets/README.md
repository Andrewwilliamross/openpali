# Tickets

Use this directory for independently assignable product, design, data, platform,
and engineering work.

Each ticket should include:

- problem and production outcome;
- scope and explicit non-goals;
- acceptance criteria;
- implementation constraints and dependencies;
- testing, observability, accessibility, and rollout requirements;
- links to the governing plan and research.

Tickets should describe outcomes rather than prescribe an implementation unless
the implementation has already been decided.
