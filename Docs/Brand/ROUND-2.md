# Field Office redesign

The first public launch established the repository and its website. The next design review rejected a monogram-led identity and asked for more individuality, a coherent world, and real medium exploration. Cua joined Omarchy, Prime Agent, and GeoLibre as a reference for the breadth of the presentation.

## Selected direction

**The Field Office: A place with footnotes.** An original coastal paper atlas, source slips, tracing sheets, and a small working pelican connect the place with the work of understanding its public record. White, cobalt, Fraunces display type, and DM Sans UI type hold the family together.

The complete alternate implementations are Living Atlas, a real Three.js folding coastal sheet, and Three Dates, an HTML/CSS mechanical instrument. They remain review studies. The production candidate uses the Field Office illustration and native HTML notes.

## Delivery checklist

- [x] Source-linked research and critique of the reference projects.
- [x] Parallel editorial, interaction, and engineering proposals.
- [x] Three distinct working websites, with desktop and mobile compositions.
- [x] Original hero and three consistent contribution-role illustrations.
- [x] Small vector companion, wordmark, favicon, ASCII, and sticker.
- [x] GitHub banner, landscape social preview, and square social card.
- [x] Responsive production website with one canonical GitHub link.
- [x] Native notes, keyboard access, no-JavaScript fallback, and reduced motion.
- [x] README integration with source and contribution journeys.
- [x] Brand guide, provenance, full prompts, font licenses, and repeatable exports.
- [x] Updated announcement drafts using the same identity.
- [x] Independent critique and revision of spacing, tablet overlap, date semantics, and focus geometry.
- [x] Explicit deployment allowlist; the application and design lab stay out of the Pages artifact.
- [ ] Publish the reviewed replacement to the main branch.
- [ ] Upload the new repository social preview in GitHub Settings.

The public launch from the previous round remains the published revision until this redesign is merged. Prepared announcement copy is not a sent social post. No license selection or account-avatar change is included.
