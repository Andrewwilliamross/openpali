# Field Notes: the flat drawing

> Archived direction. The current website uses the white-and-blue [Signal identity](README.md).

**Earlier candidate: [PR #12](https://github.com/Andrewwilliamross/openpali/pull/12).** This revision is prepared for review and has not been represented here as published on main.

The third direction keeps the pelican and field notebook, replaces the layered paper landscape with a flat drawing, and gets closer to actual Pacific Palisades parcels. White, cobalt, Fraunces, DM Sans, the headline, and the primary GitHub action continue across the family.

## Implemented

- An original SVG pelican with separate feet, head, wing, notebook, and pencil groups.
- A fixed 61-parcel County drawing around Galloway and Hartzell Streets at Bestor Boulevard, with verified street labels and retained provenance.
- A separate, labeled architectural margin study.
- A shared 26-second animation: planted waddle, inspection, pencil lift, underline, and return.
- Pause/resume, hidden/offscreen suspension, a reduced-motion still, and explicit one-cycle playback.
- Native field notes and source disclosure, with a static drawing and working GitHub link when JavaScript is unavailable.
- Matching banner, avatar, favicon, and social preview in the [current asset folder](../../assets/brand/field-notes-2d/).
- A Python scene composer and website build. The build inserts the scene SVG into HTML and stages 10 allowlisted source files plus `.nojekyll`; it needs no runtime package or external data fetch.

The parcel geometry does not animate or express rebuilding progress. The bird and architectural study are illustration. The [geography notes](../../design-lab/round-3/GEOGRAPHY.md) document the sources and reuse basis.
