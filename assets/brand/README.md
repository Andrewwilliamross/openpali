# OpenPali identity assets

The current identity is [Signal](signal/): scattered cobalt squares on white, with DM Sans and the headline **Understand the rebuild.**

Use [signal/banner.png](signal/banner.png) for the repository, [signal/social-card.png](signal/social-card.png) for previews, and the icons and editable sources in that folder. The complete [brand guide](../../Docs/Brand/README.md) covers voice, exports, and licensing notices.

Older files in this directory and the `field-office/` and `field-notes-2d/` folders are retained for the archived design studies. They are not the current artwork. Shared fonts and their licenses are in [fonts/](fonts/).
